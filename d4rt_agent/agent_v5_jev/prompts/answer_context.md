Compare each answer option with the measurements and with the description of the video.

Chronological rule: an option that names the motions in the order they happened beats one that names the largest
motion first. A path "forward, forward, turn left, left, then backward four times" is "moves forward and turns left".

How the measurement words map to option wording:
- A reversal (closer_then_farther, farther_then_closer, a path that goes and comes back) is what options call
  "fluctuating", "back and forth", "alternating" or "unstable" -- not "approaching" or "retreating".
- A label of unchanged / constant / still / eye level / static means the change stayed inside the threshold fitted on
  this benchmark. Do not overrule it with a raw ratio or a few degrees that look different. Overrule a label only when
  the description of the video clearly shows otherwise.
- A camera labelled 'static' is what options call "fixed", "stationary" or "remains still", even if the speed table
  shows small nonzero values: those are estimation noise.
Where a measurement was unavailable, or clearly contradicts the description, decide from the description.
